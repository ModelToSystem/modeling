## 1. 유스케이스

**객체 정의**

- 강의 식별: 강의는 교수, 강의실, 정원, 시간이 일치하면 같의 강의로 본다.

**신청요청 작업 순서**

1. 정원을 차감 요청 → “강의”
2. 수강 내역 등록 요청 → “등록”
3. 학생의 수강 가능 학점을 차감 시킨다. → “학생”

**신청취소 작업 순서**

1. 등록 내역 수정 → “ 등록”
2. 정원 증가 요청 → “강의”
3. 학생의 수강 가능 학점을 복구 시킨다. → “학생”

### 1.2. 수강 신청 유스케이스

**수강신청 한다.**

- 엑터: **매니저**
- 주요 성공 시나리오
    1. 정원을 감소시킨다.
    2. 수강 신청 내역을 추가한다.
    3. 학생의 수강 가능 학점을 차감한다.

**강의 정원 감소 한다.**

- 엑터: **강의**
- 주요 성공 시나리오
    1. 현재 정원 정보를 보고 자리가 있는지 확인한다. 
    2. 정원을 차감한다.

**수강 신청 내역 등록 한다.**

- 엑터: **등록**
- 주요 성공 시나리오
    - 신청 내역을 만든다.

**수강 가능 학점 차감 한다.**

- 엑터: **학생**
- 주요 성공 시나리오
    - 잔여 수강 가능 학점을 확인한다.
    - 수강 가능 학점 차감한다.

### 1.3. 수강 취소 유스케이스

**수강취소 한다.**

- 엑터: 매니저
- 주요 성공 시나리오
    1. 수강 신청 내역 상태를 "취소됨"으로 변경한다. 
    2. 강의 정원을 복구한다.
    3. 학생의 수강 신청 가능 학점을 복구한다.

**강의 정원 증가 한다.** 

- 엑터:  강의
- 주요 성공 시나리오
    - 강의 정원을 증가시킨다.

**유저 학점 증가.**

- 엑터:  학생
- 주요 성공 시나리오
    - 학생의 현재 잔여 수강 가능 학점을 복구한다.

**내역 상태 변화.** 

- 엑터: 등록
- 주요 성공 시나리오
    - 등록 신청 내역을 확인한다.
    - 신청 내역 상태를 "취소됨"으로 변경한다.

## 3. 테스트 시나리오

**매니저(통합 테스트 느낌으로 한다.)**

1. 정원을 감소 시킨다.
2. 수강 신청 내역을 추가한다.
3. 학생의 수강 가능 학점을 차감한다.

**등록**

- 등록하면 내역이 생성된다.
- 취소하면 내역이 취소 상태로 변경된다.

**강의**

- 등록하면 정원을 차감한다.
- 취소하면 정원을 복구한다.

**학생**

- 등록하면 신청 가능 학점을 차감한다.
- 취소하면 신청 가능 학점을 복구한다.
